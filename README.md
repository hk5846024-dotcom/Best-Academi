# Best Academy Website

A responsive, multi-page academy website made with HTML, CSS, and vanilla JavaScript.

## The 10 project files

1. `index.html` — Home page
2. `about.html` — About the academy
3. `courses.html` — Course listing
4. `admissions.html` — Admission enquiry form
5. `teachers.html` — Teacher profiles
6. `gallery.html` — Gallery placeholders
7. `contact.html` — Contact page and message form
8. `css/style.css` — Shared design, layout, and responsive styles
9. `js/script.js` — Mobile menu, current year, and demo form behavior
10. `README.md` — Project instructions

## Run it in VS Code

1. Extract the ZIP file.
2. Open the `best_academy_website` folder in Visual Studio Code.
3. Open `index.html` in your browser, or use the **Live Server** extension.
4. Use the navigation links to move between pages.

## Customize before publishing

- Replace the sample academy description, course details, teacher profiles, address, phone number, and email with accurate information.
- The gallery uses designed placeholders. Replace them with real photos you have permission to publish.
- The forms are front-end demonstrations only. They validate and display a message but do **not** send, email, or save submitted data. Connect a backend or trusted form service before using them with real students.
- Google Fonts are imported online; if offline, fallback fonts will be used.

No build tools or package installation are required.
